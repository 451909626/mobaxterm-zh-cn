# 构建说明

普通用户可下载 Releases 中的汉化便携包解压运行，也可使用图形化工具自行生成副本。以下是开发者构建与配置迁移说明；双包发布方式见 [RELEASES.md](RELEASES.md)。

## 独立终端菜单启动器

此工具在运行时替换菜单标题，不改写磁盘上的 MobaXterm 或 MoTTY 文件。使用者需要自己取得运行目标。

```powershell
python scripts/build_launcher.py --output dist/menu-launcher
```

将生成的 `MobaXterm_zh-CN.exe` 放到目标程序旁边，再从启动器进入。默认自动查找同目录中产品信息为 MobaXterm、版本为 26.5 或更新的 EXE；不按具体版本文件名猜测。它只处理选定文件所属的 MobaXterm 主窗口及其 CMoTTY 子窗口。关闭匹配的软件后，启动器自行退出。

同目录有多个合格 EXE 时停止并提示选择，可以启动时指定：

```powershell
.\MobaXterm_zh-CN.exe --exe MobaXterm_Personal_26.5.exe
```

也可在构建时用 `--target-exe MobaXterm_Personal_26.5.exe` 固定目标文件名。两种方式都校验产品信息与最低版本。仅检查启动器将选择哪个文件而不启动软件：

```powershell
.\MobaXterm_zh-CN.exe --inspect selection.json
```

构建时会导出已编译程序的菜单目录，与 `translations/terminal-menu.json` 比较。输出中的 `.generated` 保存生成源码与检查数据，供本地复核；不纳入 Git。

## 完整界面本地重建

这种方式修改官方 EXE 的副本，原始输入保留。项目代码许可不代替 Mobatek 的许可；公开便携包由独立发布入口筛选文件并检查，避免附带用户数据。

从[官网](https://mobaxterm.mobatek.net/download-home-edition.html)取得 26.5 或 26.6 Home 便携原包。工具根据 EXE 的版本信息自动选择清单，同时核对全部输入摘要。已登记的原包：

| 上游版本 | 官方 ZIP 的 SHA-256 |
|---|---|
| 26.5.0.5542 | `a26e7e4e2f7bd47a13fbc6d93d08a2d946f21c3e0d135b9e4f55149842c09ef6` |
| 26.6.0.5560 | `03c827c3467518de45542acba8caae63d951aede4b479962bf065b4df0d8a845` |

主程序和两个插件的逐文件摘要、官方原包地址及预期输出记录在 [26.5 清单](../patches/26.5.0.5542/version.json)与 [26.6 清单](../patches/26.6.0.5560/version.json)。先做只读检查：

```powershell
python scripts/inspect_upstream.py --source-zip "D:\Downloads\MobaXterm_Portable_v26.5.zip"
```

`full_ui_supported` 表示该输入是否通过已登记完整界面版本及摘要检查；`menu_version_eligible` 只表示达到菜单启动器的最低版本，不代表真实菜单已经完成回归。

安装依赖后，使用一个新的空输出目录：

```powershell
python -m pip install -r requirements.txt
python scripts/build_local_ui.py --source-zip "D:\Downloads\MobaXterm_Portable_v26.5.zip" --output dist/26.5
```

26.6 使用相同命令并更换原包和空输出路径，无需选择版本参数。也可用 `--source-dir` 指定已经解压、包含三个官方文件的目录。目录中只能有一个 MobaXterm EXE。原始输入只读，输出目录非空时会停止，不会覆盖现有程序或配置。未知新版、低于 26.5 的版本或摘要不符的输入在生成输出前被拒绝；不提供跳过校验的强制选项。

输出主程序名对应输入版本，从同目录的 `MobaXterm_zh-CN.exe` 运行。主程序结果必须与该版本清单一致：

| 输出主程序 | SHA-256 |
|---|---|
| MobaXterm_Personal_26.5.exe | `9b3d091f224192017cec242bca6a8eff4d7ce3a214877a60cf407ff6e907d0ac` |
| MobaXterm_Personal_26.6.exe | `670276375a2602065a941c4e1098f7d69aa19cdf82122e5b790ea6ed7d7b7553` |

R2.8 在 R2.7 基础上恢复两版各 14 处工具栏 `HelpKeyword` 的官方英文原始字节，修复选择、排序并保存按钮后工具栏消失的问题。相对 R2.7 只改变主窗体中的这些标识及 PE 校验和，非资源区段保持一致。原有关闭确认框修复保留。主工具栏标题暂时保留英文，设置页、提示和其他界面继续汉化；实际验证范围见[验证记录](VALIDATION.md)。启动器不嵌入厂商图标，编译后的 36 项菜单数据会独立核对。

26.6 的 R2.9 在 R2.8 基础上增加受审的工具栏显示适配：一处标题设置调用与两处布局读取调用重定向到独立的只读可执行区段。14 个已知按钮的标题映射为中文，布局读取保持英文标识；未知控件继续走原有读取逻辑。三个原调用共 15 字节逐一校验，其他原有区段相对 R2.8 不变，所有资源和原始英文 `HelpKeyword` 均不变。新增机器码通过两个装载基址下的 80 组执行检查，并从官方原包完整重建得到与用户复测候选一致的字节。该适配仅登记于 26.6，不能套用于其他版本。

26.6 的 R2.10 在 `TFORMPARAMS` 中增加 110 处下拉选项及默认显示文字替换，限定为 `settings.py` 中列出的精确控件、原文与译文。除这一个资源外，其他窗体不变。大部分选项按 `ItemIndex` 保存，保持选项数量与顺序即可保留含义；默认主页、新标签页和 X11 缩放使用文字保存，因此单独校验六处原调用及参数来源，在只读可执行的 `.zhset` 区段适配加载和保存。旧英文值对应原序号，保存仍使用原文；自定义名称、数字 DPI 和不匹配项回退原生函数。六处原代码合计 30 字节，两个装载基址下的加载、保存、大小写、空值及自定义项执行检查通过。先独立更新已审资源基线，再从官方 ZIP 完整重建，两者摘要必须一致。

26.6 的 R2.11 新增 35 个会话下拉控件及 15 个二级窗口下拉控件的显示白名单，共 245 条选项文字。`session_options.py` 限定精确控件、原文与译文，`session-values.json` 登记需要适配的调用位置，封装工具会携带同一份清单。资源选项数量、顺序、默认序号和事件保持原样。19 个控件涉及连接字符串、旧值查询或特殊选项比较，先调用原生函数，再对已知标签还原原文，或在原查询失败后重试中文标签；未知值继续使用原生逻辑。配色中内置项以外的自定义名称不转换，编码标识及目录路径保留。

R2.11 还补译 21 处遗漏的静态按钮标题，并适配会话窗口、目录选择器和颜色选择器运行时覆盖的 9 个按钮标题；编码下拉框的一处运行时赋值单独适配。共 59 处原调用、295 个现有代码字节重定向到只读可执行的 `.zhss` 区段，原有点击事件及英文功能字符串保持不变。共享会话窗口重新生成的“共享文件夹”选项使用一处带唯一引用校验的显示常量补丁。原包完整重建与独立资源基线重建必须逐字节一致。真实界面验收状态见[验证记录](VALIDATION.md)。

26.6 的 R2.12 补译 `TreeSessionsContextPopup` 在右键弹出时重新赋值的 22 处显示常量。30 个指针引用全部限定在该方法内，按 Delphi AnsiString 长度头和 GBK 原容量更新，动态数量及来源会话名称的拼接保留。相对 R2.11 仅改变这些常量存储及 PE 校验和共 417 个字节，全部窗体、事件、调用指令和三个适配区段均不变。完整重建结果需与从 R2.11 只更新上述常量得到的基线一致。

26.6 的 R2.13 增加 `connection-prompts.json` 的 64 条显示规则与 `prompt-sites.json` 的五处精确调用记录。四处原生模态调用和一处输入框说明设置调用合计 37 字节，经原字节及前置参数来源校验后转到只读可执行的 `.zhpr` 区段。通用消息框先按原文完成“不再显示”标识与“More info...”布局判断，再临时转换已审标题、正文和按钮，调用原生弹窗一次，保留返回结果并恢复原英文标题。保存密码框只处理说明标签；输入框只处理提示参数，不读取密码编辑框。模板中的动态内容按原字节复制，未知或有歧义的文本保留原文。

R2.13 另补五处指纹详情窗口标题和七处原生主密码错误、强度与遗失警告。资源验证事件、实际指纹值、主机信任配置、凭据存储格式及旧消息标识不变。64 条规则编译为 79 个纯文本/HTML 变体，在两个装载基址下核对变量字节、模态结果、内部标题恢复、未知消息回退与内存释放；完整原包重建必须与独立资源基线结果一致。封装工具携带同一份新增清单，适配仍只支持 26.6.0.5560，实际连接弹窗验收状态见[验证记录](VALIDATION.md)。

完整构建会移除已失效的厂商签名数据并重新计算 PE 校验和，不会伪装原厂签名。官方原始输入保留原样。

## 复制旧配置并适配历史引用

关闭相关软件后，将旧配置复制到新的配置路径：

```powershell
python scripts/migrate_profile.py --source "D:\OldPortable\MobaXterm.ini" --output "D:\NewPortable\MobaXterm.ini"
```

输出文件必须不存在。工具只修改 `[Recently started]` 和 `[LastInstanceSessions]` 中数字项的默认 `User sessions\` 根目录引用，保留其他所有原始字节；不重命名用户会话、不解密或导出凭据。迁移幂等，源文件不改写。

## 本地构建数据

`dist/`、`.local/`、可执行文件、插件、INI、日志和完整软件压缩包均由 Git 忽略。本页的界面构建入口不下载软件或发布 Release；独立发布入口会下载并校验官方原包、构建双包并发布。均不自动打开主程序建立会话。
